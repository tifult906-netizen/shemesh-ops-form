התקנה ראשונית

  • מסלול מהיר: סקריפט אחד שמתקין הכל אוטומטית (מומלץ)
  • מסלול ידני: שלב אחר שלב עם כפתורי הורדה ופקודות להעתקה

זוהינו אוטומטית את מערכת ההפעלה שלך — אפשר לעבור בין הלשוניות.

⚡ מסלול מהיר — סקריפט אחד שמתקין הכל

פתח PowerShellTerminalTerminal והדבק את הפקודה הבאה. הסקריפט יתקין Python + Git + Ollama, יוריד את הכלי, ויפעיל אותו.

שלב 1: פתח PowerShell כמנהל — לחיצה ימנית על תפריט התחל → "Terminal (Admin)" או "Windows PowerShell (Admin)".

שלב 2: העתק את הפקודה הבאה והדבק בחלון PowerShell שנפתח, אז Enter:

[Net.ServicePointManager]::SecurityProtocol='Tls12'; iex (New-Object Net.WebClient).DownloadString('https://tifult906-netizen.github.io/shemesh-ops-form/scripts/setup-windows.ps1')
מריץ מ-cmd / מ-Run? (פקודה אלטרנטיבית)

אם אתה מדביק את הפקודה בחלון cmd או בדיאלוג Run במקום בתוך PowerShell, השתמש בגרסה הזו (היא קוראת ל-powershell.exe ושולחת לו את הפקודה):

powershell -NoProfile -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol='Tls12'; iex (New-Object Net.WebClient).DownloadString('https://tifult906-netizen.github.io/shemesh-ops-form/scripts/setup-windows.ps1')"

או הורד את הסקריפט כקובץ: setup-windows.ps1 ולחץ עליו לחיצה ימנית → Run with PowerShell.

שגיאות נפוצות וכיצד לפתור

"-NoProfile is not recognized" — הדבקת את הפקודה הארוכה בתוך PowerShell. PowerShell מנסה להריץ את `-NoProfile` כפקודה. השתמש בגרסה הקצרה למעלה (זו שמתחילה ב-[Net.ServicePointManager]).

"running scripts is disabled" — סגור את החלון ופתח PowerShell כמנהל.

"winget לא מזוהה" — Windows שלך ישן. עדכן את "App Installer" מ-Microsoft Store, או השתמש במסלול הידני למטה.

"python is not recognized" אחרי שלב 1 — סגור את PowerShell ופתח חלון חדש (כדי לרענן PATH), אז הרץ את הסקריפט שוב — הוא יזהה מה כבר מותקן וידלג.

שגיאת TLS / קישוריות — וודא חיבור אינטרנט יציב; VPN לפעמים חוסם.

curl -fsSL https://tifult906-netizen.github.io/shemesh-ops-form/scripts/setup-mac.sh | bash

או הורד את הסקריפט ידנית: setup-mac.sh

curl -fsSL https://tifult906-netizen.github.io/shemesh-ops-form/scripts/setup-mac.sh | bash

(הסקריפט עובד גם על Linux — בודק apt / dnf / pacman אוטומטית)

או — מסלול ידני, שלב אחר שלב

1

התקן Python 3.11 ומעלה

שפת התכנות שעליה הכלי בנוי. מתקין פעם אחת ועובד לתמיד.

הורד מ-python.org → חשוב: סמן "Add Python to PATH" במסך הראשון של ההתקנה
או דרך winget (אם יש לך Windows 11 / 10 מעודכן)
winget install Python.Python.3.11
הורד מ-python.org →
או דרך Homebrew
brew install python@3.11
sudo apt-get install -y python3 python3-venv python3-pip
2

התקן Git

כדי להוריד את קוד הכלי מ-GitHub.

הורד Git for Windows →
או דרך winget
winget install Git.Git
הורד Git for macOS →
או דרך Homebrew
brew install git
sudo apt-get install -y git
3

התקן Ollama

הריצה המקומית של מודל הראייה (קורא את ה-PDFs בעברית). פועל ברקע.

הורד Ollama for Windows →
או דרך winget
winget install Ollama.Ollama
הורד Ollama for macOS →
או דרך Homebrew
brew install ollama
curl -fsSL https://ollama.com/install.sh | sh
4

הורד את מודל הראייה (~5GB, פעם אחת)

פתח Terminal / PowerShell והרץ:

ollama pull qwen2.5vl:7b

ההורדה לוקחת בין 5 ל-15 דקות תלוי באינטרנט
